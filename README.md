# Skills

Skills personales para Claude Code.

| Skill | Qué hace |
|---|---|
| [dashboard](dashboard/SKILL.md) | Tableros HTM autocontenidos desde Excel/TXT: pantalla inicial de importación y export en modo lectura (solo imprimir/PDF). |

## Instalar

```bash
git clone https://github.com/cdponte91/Skills.git
cp -R Skills/dashboard ~/.claude/skills/
```

Reiniciar Claude Code.
